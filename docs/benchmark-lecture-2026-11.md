# Benchmark lecture immersive (novembre 2026)

Concurrents : Wattpad, Inkitt/Galatea, Radish, Webnovel, Dreame, AO3, Fyctia (FR) ; references lecture : Kindle, Apple Books, Medium.

## Constats
- Reglages de lecture (taille, police, themes clair/sepia/nuit) : Wattpad, Apple Books, Kindle.
- Temps restant : Kindle (chapitre/livre), Medium (~265 mots/min).
- Commentaires par paragraphe : Wattpad, Webnovel (fort levier d'engagement).
- Immersion sonore (musique, effets, haptique) : Galatea uniquement.
- Monetisation par attente/pieces/pass quotidiens : Radish, Webnovel, Dreame (percue comme casino) ; seuil de likes : Fyctia.

## Retenu pour Love Ink (livre le 2026-11-05)
1. Mode lecture "Aa" : taille, interligne, police, ambiances Auto/Rose/Sepia/Nuit (memorise).
2. Temps de lecture (230 mots/min) + temps restant + barre de progression.
3. Reprise de lecture proposee (jamais forcee).
4. Mode focus (masque nav/commentaires, plein ecran).
5. Lettrine, typographie de page de livre, separateurs de scene (`* * *` -> ornement).
6. Fin d'histoire : suggestions "A lire ensuite" (meme categorie d'abord).

## Ensuite
- Rangee "Continuer a lire" et histoire a la une dans le feed.
- Commentaires par paragraphe (champ `paragraphe` sur `commentaires` + regle Firestore).
- Ambiance sonore optionnelle, desactivee par defaut.

## A eviter
Pieces/attente pour debloquer, suspense paye ou conditionne aux likes, scroll-jacking, son en lecture auto, pubs entre chapitres, temps restant trop optimiste.
